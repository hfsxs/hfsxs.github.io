Ansible自动化运维工具常用模块

Ansible自动化运维工具常用模块

1.command

Ansible默认模块，远程主机执行命令时不经过其Shell处理，不支持管道符、重定向和变量 

ansible hosts -m command -a 'uptime'
# chdir，执行命令前先切换到指定目录
ansible hosts -m command -a 'chdir=/root ls -l'

2.shell

Ansible基础模块，远程主机执行命令时经过其/bin/sh程序处理，支持管道符、重定向和变量 

ansible master -m shell -a 'chdir=/root ps -ef|grep keepalived|grep -v grep'

3.yum/apt

Ansible，用于管理远程主机的RPM/DEB包，执行安装、升级及卸载操作

参数详解

  • name，包名字
  • state，对包进行的操作，latest/installd/present表示安装，removed/absent表示卸载
# 安装最新版本docker
ansible hosts -m yum -a 'name=docker state=latest'
# 安装指定版本软件包
ansible hosts -m apt -a 'name=docker-20. state=present'
# 将所有软件包升级到最新版本
ansible hosts -m apt -a 'name=* state=latest'

# 卸载软件包
ansible hosts -m yum -a 'name=docker state=absent'

4.copy

Ansible文件分发模块，用于将控制主机的文件复制到受控主机的指定目录，功能类似于scp

参数详解

  • src，必选项，本地文件路径
  • dest，必选项，远程主机路径
  • backup，默认为no，设为yes将会在目标端生成带时间戳的备份文件
  • owner/group/mode，设置目标端文件的属主、属组和权限，默认与控制主机一致
ansible hosts -m copy -a 'src=/root/docker dest=/root'
# 将本地文件复制到受控主机，若内容不同则执行备份操作
ansible hosts -m copy -a 'src=/etc/hosts dest=/etc backup=yes'
# 将本地文件复制到受控主机，并修改文件权限
ansible hosts -m copy -a 'src=/root/docker- dest=/home/sword owner=sword group=sword mode=755'
# 分发目录时，src路径末尾不带/‌，则将整个目录复制到目标端路径，带/‌则只会复制目录内的文件到目标路径，不包括目录本身
ansible hosts -m copy -a 'src=/root/docker/ dest=/usr/bin'

5.unarchive

Ansible解压归档压缩包的模块，用于将控制主机的压缩文件分发到受控主机的指定目录，并解压

参数详解

  • src，必选项，控制主机的压缩包文件路径
  • dest，必选项，目标主机压缩包解压的路径
  • copy，是否拷贝压缩包文件到远程主机，默认为yes，no则表示在远程主机搜索压缩包文件
  • owner/group/mode，设置目标端文件的属主、属组和权限，默认与控制主机一致
ansible hosts -m unarchive -a 'src=docker-20.10.16.tgz dest=/root'
ansible hosts -m unarchive -a 'src=/root/apache-tomcat-10.0.20.tar.gz dest=/usr/local mode=755'

6.service

Ansible系统服务管理模块，用于启动、停止、重启、重载及设置开机自启目标端的服务，要求目标端主机的服务须通过BSD init,、OpenRC、SysV、Solaris SMF、systemd、
upstart中的任意一种所管理

参数详解

  • name，必选项，服务名称
  • state，必选项，服务状态，started表示启动，stopped表示停止，restarted表示重启，reloaded表示重载
  • enabled，yes表示设为开机自启，不指定则保持不变
ansible hosts -m service -a 'name=docker state=started enabled=yes'

7.file

Ansible文件管理模块，用于管理目标主机的文件、目录及其权限，如文件或目录的创建、删除、权限修改及链接，不传输文件内容

参数详解

  • path，别名src（link）或dest，必选项，目标主机上所要管理文件或目录的绝对路径
  • state‌，对文件或目录的操作，默认为file，表示文件操作；directory，创建目录；touch，创建空文件或更新时间戳；link/hard，创建软/硬链接；absent，删除文件或目录，等价于rm -rf
  • mode‌，权限配置，如644、600或755等
    ‌- owner‌/‌group‌，设置所有者及所属组，需用户在目标主机存在
    ‌- recurse‌，设为yes表示递归修改目录下所有文件的属性，默认为no，只修改文件权限
    ‌- force‌，state=link时，若目标存在或源文件不存在，则强制创建或覆盖链接
# 创建目录，并指定权限
ansible ops -m file -a 'path=/tmp/test state=directory mode=755 owner=ops group=ops'
# 创建空文件，并指定权限
ansible ops -m file -a 'path=/tmp/test/test.txt state=touch mode=600 owner=nginx group=nginx'
# 递归修改目录权限
ansible ops -m file -a 'path=/tmp/test state=directory mode=755 owner=nginx group=nginx recurse=yes'
# 创建软连接
ansible ops -m file -a 'src=/tmp/test/test.txt state=link dest=/tmp/test.txt'
# 删除文件或目录
ansible ops -m file -a 'dest=/tmp/test state=absent'

8.lineinfile

Ansible按行管理文件的模块，用于精确修改文件单行内容，可替换、插入、删除行，且天然幂等，多次执行结果一致，功能类似于sed

参数详解

  • path，必选项，所操作的文件路径
  • line，必选项，所要写入的整行内容，为空则表示为空行
  • regexp‌，正则匹配所要操作的行，替换或删除，不指定则将line的内容追加到文件末尾
  • ‌state‌，默认为present，表示替换操作，absent则表示删除操作
  • insertbefore/insertafter‌，插入操作，在匹配行之前/之后插入新行，支持正则或BOF/EOF
  • backup‌，默认为no，表示不备份直接修改文件，生产环境建议设为yes
    ‌- create‌，默认为no，表示文件不存在时不进行创建
    ‌- backrefs‌，开启正则后向引用，且匹配不到时不追加行
    ‌- validate‌，修改前执行校验文件语法，如nginx -t
ansible ops -m lineinfile -a 'path=/etc/selinux/config regexp=SELINUX=enforcing line=SELINUX=disabled'
# 将000这一行替换为111，匹配不到则将追加在文件末尾
ansible ops -m lineinfile -a 'path=/root/t.txt regexp=000 line=111'
